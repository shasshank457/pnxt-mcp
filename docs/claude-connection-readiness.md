## Five highest-priority actions

1. Confirm the production `MCP_PUBLIC_BASE_URL` matches the public hostname used by the metadata challenge.
2. Choose fixed-client or CIMD; configure the exact fixed callback, or configure and verify the CIMD allowlist and metadata document.
3. Verify public HTTPS routing for `/mcp`, both `/.well-known/*` endpoints, and `/oauth/*` through the reverse proxy/Cloudflare layer.
4. Run one authorized PointNXT login and consent flow, confirming the intended tenant and membership are attached.
5. Complete the first Claude end-to-end test, then verify MCP access, refresh rotation, revoke/disconnect, and redacted logs.
